# Say hello to Saturn
A lightweight, highly customisable code editor. It's so good, we use it to make it.

# Language support
Saturn has modules for C#/.NET, Data and Storage formats, and Markdown.

You can write your own languages and add them to the marketplace at https://github.com/Saturn-Editor/Marketplace

# Customise Saturn
Saturn supports custom themes and key bindings. There's themes and key bindings available for Visual Studio and IntelliJ for developers moving from those platforms.

Saturn also supports code modules, which add additional functionality to the editor.

You can write your own themes and modules and add them to the marketplace at https://github.com/Saturn-Editor/Marketplace
