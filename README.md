# Say hello to Saturn
A lightweight, customisable, and extensible code editor. It's so good, we use it to make it.

Saturn is entirely modular. By default it is a simple text editor, but with language and code modules, it comes alive. You choose what you want to run, making this one of the most lightweight code editors out there.

Saturn's powerful API enables languages, code modules, and themes to make your experience come alive. Developers are welcome to create their own additions and submit them to the marketplace at https://github.com/Saturn-Editor/Marketplace

## Language support
Saturn has modules for C#/.NET, Data and Storage formats, and Markdown.

## Customise Saturn
Saturn supports custom themes and key bindings. There's themes and key bindings available for Visual Studio and IntelliJ for developers moving from those platforms.

Saturn also supports code modules, which add additional functionality to the editor.
